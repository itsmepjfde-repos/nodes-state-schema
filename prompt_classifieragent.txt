Generate a Python file named `defect_classifier_agent.py` that defines a LangChain agent for defect classification.

### Requirements:
1. **Input Modes**
   - Standalone CLI: Accept a Jira defect ID from command line.
   - LangGraph: Accept and update `state` variables when orchestrated.

2. **Jira Integration**
   - Implement Jira API calls as LangChain Tools.
   - Fetch defect title and description using Jira REST API.
   - Keys and configs must be read from `.env`:
     - `JIRA_BASE_URL`
     - `JIRA_API_KEY`
     - `JIRA_EMAIL`
     - `GEMINI_API_KEY`
     - `GEMINI_MODEL`

3. **Classification Categories**
   - Agent must classify defects into one of the following service/features:
     - catalog, order, payment, inventory, shipping, notification, others
   - Apply alias mapping:
     ```python
     CATEGORY_ALIASES = {
         "products": "catalog",
         "product": "catalog",
         "orders": "order",
         "payments": "payment",
         "stock": "inventory",
         "delivery": "shipping",
         "notifications": "notification",
     }
     ```
   - Normalize classification results using aliases.

4. **LangChain Best Practices**
   - Use `PromptTemplate` for classification prompt.
   - Use `ChatGoogleGenerativeAI` (Gemini wrapper) as the LLM.
   - Use `StrOutputParser` for clean category output.
   - Wrap Jira API calls in a `Tool` abstraction.
   - Chain composition: `PromptTemplate | LLM | StrOutputParser`.

5. **Agent Functions**
   - `build_classifier_chain()` → returns the classification chain.
   - `fetch_jira_defect(jira_id)` → Jira API call tool.
   - `classifier_node(state)` → LangGraph node function:
     - Reads `jira_id` from state.
     - Fetches defect details.
     - Runs classification chain.
     - Updates `state["classification"]`.

6. **Error Handling**
   - If Jira defect not found → classification = "others".
   - If insufficient info → classification = "others".
   - Log errors gracefully.

7. **CLI Support**
   - If run directly (`__main__`), accept Jira ID from command line.
   - Print classification result to stdout.

### Deliverable:
- A **modular, production‑ready agent file** (`defect_classifier_agent.py`) that can:
  - Run standalone from CLI.
  - Plug into LangGraph orchestration.
  - Follow LangChain best practices for tools, chains, and agents.
